name: Compact status badges
description: User preference for the footprint of read-only status labels and Visit Expired badges
---

Keep read-only status badges compact, including Visit Expired and the Walk-in Visitor classification when it appears beside a request status. Match the original small request-status typography and tight padding rather than enlarging all badges for consistency.

**Why:** The user corrected a standardization pass that made status badges visibly larger. They specifically preferred the earlier status badge size, asked for Visit Expired to match it, and pointed out that the adjacent Walk-in Visitor badge in request details was still larger.

**How to apply:** When styling status labels or nearby classification badges on cards and detail headers, preserve the shared compact footprint. Changes to explanatory notices need not turn their body text into badge text.

For Arabic badges, distinguish the centered text line box from the visible
glyphs' optical center.

**Why:** Caption metrics and row centering alone did not resolve the user's
reported alignment. Their screenshot still placed the visible Arabic glyphs
above the badge center. The user asked for the text alignment, not larger pills.

**How to apply:** Keep any optical correction limited to Arabic label text;
preserve the compact container, English metrics, and independently centered icon.
Check actual browser rendering as well as style assertions.
