GET
/api/v1/invites/{token}
Get invitation details and redirect

Verifies the invitation using the unique token and redirects to the visitor portal. Use format=json query parameter to get JSON response instead of redirect. This is a public endpoint that does not require authentication.

Parameters
Cancel
Name	Description
format
(query)
Set to "json" to return JSON instead of redirecting

json
token *
(path)
The unique invitation token sent to the visitor
