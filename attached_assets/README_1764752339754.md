# VMS Backend API - Frontend Integration Guide

## Quick Start

### Step 1: Copy Files to Your Frontend Project

Copy these two files to your frontend Replit project:
- `vms-api-types.ts` - TypeScript types and interfaces
- `vms-api-client.ts` - API client with all endpoints

### Step 2: Update the Backend URL

In `vms-api-client.ts`, update the `API_BASE_URL` constant:

```typescript
const API_BASE_URL = 'https://6dd8abd4-1ba4-4930-9228-1c309ae5d4e2-00-2v2xb6f19be8f.sisko.replit.dev';
```

### Step 3: Import and Use

```typescript
import { vmsApi, ApiError } from './vms-api-client';
import type { User, Invitation, Visitor } from './vms-api-types';
```

## Usage Examples

### Check API Health

```typescript
const health = await vmsApi.health.check();
console.log(health.status); // "ok"
```

### Authentication

```typescript
// After Azure AD login, exchange token
const authResult = await vmsApi.auth.azureLogin(azureAccessToken);
vmsApi.setAccessToken(authResult.accessToken);

// Get current user
const me = await vmsApi.auth.me();
console.log(`Logged in as: ${me.firstName} ${me.lastName}`);

// Logout
await vmsApi.auth.logout();
vmsApi.setAccessToken(null);
```

### Users

```typescript
// List all users
const users = await vmsApi.users.list({ page: 1, limit: 20 });

// Get user by ID
const user = await vmsApi.users.getById('user-uuid');

// Create user (requires building_admin role)
const newUser = await vmsApi.users.create({
  email: 'john@example.com',
  firstName: 'John',
  lastName: 'Doe',
  role: UserRole.EMPLOYEE,
});

// Get all managers
const managers = await vmsApi.users.getManagers();
```

### Visitors

```typescript
// Create a visitor
const visitor = await vmsApi.visitors.create({
  email: 'guest@company.com',
  firstName: 'Jane',
  lastName: 'Smith',
  company: 'ACME Corp',

// Search visitors

// Blacklist a visitor
```

## Error Handling

```typescript
import { vmsApi, ApiError } from './vms-api-client';

try {
  const user = await vmsApi.users.getById('invalid-id');
} catch (error) {
  if (error instanceof ApiError) {
    console.error(`API Error ${error.status}: ${error.message}`);
    
    if (error.status === 401) {
      // Token expired, redirect to login
    } else if (error.status === 403) {
      // Forbidden, show permission error
    } else if (error.status === 404) {
      // Not found
    }
  }
}
```

## React Example

```tsx
import { useState, useEffect } from 'react';
import { vmsApi } from './vms-api-client';
import type { Invitation } from './vms-api-types';

function TodaysVisitors() {
  const [invitations, setInvitations] = useState<Invitation[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    async function fetchData() {
      try {
        const data = await vmsApi.invitations.getToday();
        setInvitations(data);
      } catch (err) {
        setError('Failed to load visitors');
      } finally {
        setLoading(false);
      }
    }
    fetchData();
  }, []);

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div>
      <h2>Today's Visitors ({invitations.length})</h2>
      <ul>
        {invitations.map((inv) => (
          <li key={inv.id}>
            {inv.visitor?.firstName} {inv.visitor?.lastName} - {inv.status}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

## API Endpoints Reference

| Module | Base Path | Description |
|--------|-----------|-------------|
| Health | `/health` | Health check |
| Auth | `/api/v1/auth` | Azure AD SSO |
| Users | `/api/v1/users` | User management |
| Visitors | `/api/v1/visitors` | Visitor profiles |
| Invitations | `/api/v1/invitations` | Visit invitations |
| Requests | `/api/v1/requests` | Approval workflow |
| Parking | `/api/v1/parking` | Parking management |
| Meeting Rooms | `/api/v1/meeting-rooms` | Room bookings |
| Buffet | `/api/v1/buffet` | Buffet service |
| Valet | `/api/v1/valet` | Valet parking |
| Notifications | `/api/v1/notifications` | Notifications |
| Gates | `/api/v1/gates` | Gate access |
