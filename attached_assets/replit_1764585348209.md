# Visitor Management System (VMS) Mobile App

## Overview
The Visitor Management System (VMS) is a comprehensive React Native and Expo mobile application designed to streamline visitor management within an organization. It features a modern dashboard interface with responsive sidebar navigation and visual analytics. The app supports nine distinct user roles (Employee, Manager, Receptionist, Security, Building Admin, Buffet Admin, Buffet Staff, Valet Admin, Valet Driver), providing specialized interfaces for managing visitor requests, check-ins, parking, valet services, and buffet bookings. Visitors interact via unique external invitation links (email, WhatsApp, SMS) to accept/reject visits through a lightweight web view. The system is branded with Dallah Albaraka's color scheme (Orange #FF8C00, Green #008B45) and defaults to a light mode theme, ensuring full theme consistency across all screens. The current focus is on UI/UX design and visual analytics demonstrations using mock data, without active backend integrations.

## System Architecture

The VMS app adheres to a Clean Architecture pattern, segmenting the application into Presentation, Business Logic (Domain), and Data layers.

**UI/UX Decisions:**
-   **Color Scheme:** Dallah Albaraka branding (Primary: Orange #FF8C00, Secondary: Green #008B45) with centralized theme management for consistency across 25+ screens.
-   **Navigation:** Dashboard-style interface featuring a responsive, collapsible left sidebar with touch-swipe gestures for mobile and a hamburger menu for desktop. Supports RTL for swipe direction.
-   **Theme:** Default light mode, with a dark mode toggle available in settings.
-   **Components:** Reusable, themed UI components including text, views, cards, status badges, form inputs, and a DashboardLayout wrapper.
-   **Visual Analytics:** Role-specific KPI cards and simple progress bar visualizations using mock data.
-   **Design System:** Comprehensive design system inspired by iOS 26 liquid glass, with consistent typography.

**Technical Implementations:**
-   **Core Technologies:** React Native, Expo, TypeScript.
-   **Iconography & RTL Support:** A comprehensive `DDIcon` component provides theme-aware icons with automatic RTL mirroring for directional icons. Logical spacing properties (e.g., `marginStart/End`) and i18n utilities (`useLocaleDirection` hook) ensure full RTL compatibility.
-   **State Management:** Centralized state service (`visitorRequestState.ts`) utilizing mutable mock data and `useFocusEffect` hook for reactive data updates across screens.
-   **Folder Structure:** Organized for clarity into `components`, `screens` (role-specific), `navigation`, `services` (mock), `domain`, `utils`, `types`, `constants`, `hooks`, and `assets`.
-   **Role-Based Access:** Specialized interfaces and navigation flows for nine distinct user roles. The Visitor role is externalized via invitation links.
-   **Navigation Implementation:** Stack Navigator with a `DashboardLayout` wrapper, and `ScreenWrapper` for navigation state management, including automatic sidebar closure on mobile.
-   **Mock Data:** Extensive mock data simulates real-world scenarios for all entities (visitor requests, parking, valet, buffet, notifications, admin KPIs).
-   **VMS Entity Types:** Defined entities include `VisitorRequest`, `Employee`, `Admin`, `SecurityPersonnel`, `ParkingSlot`, `ValetService`, `BuffetBooking`, `MeetingRoom`, `Notification`, and `CheckInRecord`.
-   **Approval Workflow:** Implements a complete manager approval workflow with options to approve/reject requests, schedule reminders, and ensure reactive state propagation.

**Features:**
-   **Login & Role Selection:** Allows quick access to nine user roles.
-   **Dashboard Interface:** Modern sidebar with user profile, dark mode toggle, and logout.
-   **Employee Flow:** Dashboard with recent requests, upcoming visitors, visitor request form with communication channel selection, request details, and cancel request functionality.
-   **Manager Flow:** Includes request creation (auto-approved), "My Requests," and a "Pending Approvals" dashboard with approve/reject actions and reminder scheduling.
-   **Visitor Flow:** Externalized via `VisitorInvitationView` for accepting/rejecting visits through a lightweight web view.
-   **Receptionist Flow:** Today's Visitors dashboard with search, and a Walk-In Registration form.
-   **Security Flow:** Check-In interface (QR scanner, expected visitors), Gate Control (code scanner, access validation), and Visitor Lookup.
-   **Admin Flows:** Role-specific dashboards for Building Admin (parking), Buffet Admin (buffet bookings), and Valet Admin (valet tasks, driver assignment).
-   **Valet Driver Flow:** Dedicated screens for assigned tasks, task details, and status updates (Accept, Start, Complete).
-   **Buffet Staff Flow:** Buffet Board for managing tasks with filterable status tabs and modal-based status updates.
-   **Admin Console (Building Admin):** Comprehensive administration interface including Building Dashboard, Users & Roles management, Parking & Valet Settings, Buffet Settings, and System Rules configuration.
-   **Shared Features:** Notifications screen, Settings for profile and app preferences, consistent branding, and a functional cancel request workflow.
-   **Responsive Design:** Adaptive UI with sidebar collapsing on mobile and always visible on desktop.
